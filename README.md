# Lovable Pro

Lovable Pro is a Chrome extension for a streamlined Lovable workflow, project guidance, prompt tools, and license-based access.

Current version: **3.1**

## Installation

1. Download or clone this repository.
2. Open `chrome://extensions` in Google Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the project folder.
